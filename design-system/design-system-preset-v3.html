component reference

every chart in the portfolio should compose from this single set of primitives. the class names are deliberately short: .nc = node component, .ce = chart edge, .ca = chart annotation.

nodes

  • .ncnode group — set data-kind to "hub", "machine", or "external" for variants
  • .nc-card<rect> — fill, stroke, shadow via CSS variables
  • .nc-kickermuted eyebrow text above the title
  • .nc-titleprimary label in node ink color
  • .nc-metasecondary detail line
  • .nc-port<circle> — connection anchor, orange with white stroke

edges

  • .cesolid route edge — orange, 1.6px stroke
  • .ce[data-kind="callout"]dashed annotation connector
  • .ce[data-kind="boundary"]muted grey boundary line, wider dash

annotation

  • .cacallout annotation group
  • .ca-cardbackground rect — paper fill, hairline stroke, soft shadow
  • .ca-labelbold heading text
  • .ca-detailbody detail text

animation helpers

  • .anim-nodepop-in entrance for nodes — set --delay in ms
  • .anim-edgedraw-in entrance for edges — set --delay in ms
  • .anim-notepop-in entrance for annotations
  • .anim-labelfade-up for text inside annotations

CSS variables (set on .chart-surface)

  • --cnnode card fill (default white)
  • --cn-linenode card stroke
  • --cn-inknode title text color
  • --cn-mutednode kicker / meta text color
  • --cn-routeedge and port color (defaults to accent)
  • --cn-hubhub node background
  • --cn-machinemachine node background

usage pattern

the outer <g> carries the SVG transform attribute for positioning. the inner <g> carries the component class and animation. this separation prevents CSS transform in keyframes from overriding layout.

<!-- correct: position on outer, animate on inner --> <g transform="translate(40 110)"> <g class="nc anim-node" data-kind="hub" style="--delay:360ms"> <rect class="nc-card" width="150" height="82" rx="6" /> <text class="nc-kicker" x="18" y="22">runtime</text> <text class="nc-title" x="18" y="45">planner</text> <text class="nc-meta" x="18" y="65">builds route</text> <circle class="nc-port" cx="0" cy="41" r="4" /> <circle class="nc-port" cx="150" cy="41" r="4" /> </g> </g> <!-- edge: single <path> with both classes --> <path class="ce anim-edge" style="--delay:520ms" d="M190 141C215 141 230 141 250 141" marker-end="url(#arr)" /> <!-- annotation: .ca with .anim-note --> <g transform="translate(460 244)"> <g class="ca anim-note" style="--delay:1520ms"> <rect class="ca-card" width="210" height="64" rx="10" /> <text class="ca-label" x="16" y="28">sequence note</text> <text class="ca-detail" x="16" y="50">explain why the edge matters</text> </g> </g>
