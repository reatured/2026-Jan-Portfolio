Two layers

src/index.css
project-story-ribbon.css

The site runs two visual systems on one screen. The poster shell is the page itself — cream ground, Archivo, faint twelve-column rules, orange accent. The Apple content layer lives inside every expanded project — a grey canvas, white cards, system UI type. The hand-off is a token remap: .project-story reassigns the shell's own token names, so a component written against var(--color-cream) renders as a white card without knowing which layer it is in.

Layout

1240px column
12-column grid

The content column never touches the viewport edge. At any width there is a minimum 24px margin, so a wide display shows generous side margins instead of a full-bleed spread. Poster sections sit on a visible twelve-column grid whose rules are inset to align with the gutters rather than spanning the viewport.

Motion answers a person's action. Two curves cover the whole site: a small-overshoot spring for lifts and settles, and Apple's ease-out for geometry. Colour and opacity run 160–240ms, transforms 260–420ms, Hero geometry 560ms.

Geometry 560ms · copy fades 240ms after

Geometry and the image transform share one duration and curve, so they cannot drift apart mid-transition. Promotional copy waits for the panel to finish expanding — 240ms opacity delayed by --hero-motion-duration. Outgoing copy hides immediately and any pending reveal is cancelled. This is what stops headline text appearing inside a narrow column.

Reduced motion

src/index.css:546-549 is a global kill switch — animation, transition, and smooth scrolling are all disabled under prefers-reduced-motion: reduce. This page honours it too; the curve demos above will be static. Components that gate behaviour on motion must still work when it fires, and several ship a manual step or replay control for exactly that case. prefers-reduced-transparency: reduce separately drops the mobile chapter rail's blur.

Apple principles

apple-design skill family
Installed 19 Sep 2026

The site was audited against the apple-design hub and its restraint-and-antislop checklist. Most of it already passes — the content layer was built to HIG in the first place. Two rows are genuine gaps and one is a deliberate divergence worth naming out loud rather than silently "fixing".

What this means in practice

Apply from Apple

  • Promote the one-off greys to named tokens so both layers stay semantic.
  • Keep the utility motion budget inside projects; springs under 300ms there.
  • Keep deferring to content — chrome stays quiet, media keeps its source ratio.
  • Keep the two-curve vocabulary; do not add a third easing.
  • Let whitespace do the work before adding a border or a background.

Do not import

  • Liquid Glass on cards — the poster shell's paper surface is the identity.
  • System blue, or any second accent. Orange is the only one.
  • Scroll-jacking or pinned cinematic scenes on the index. It is a document.
  • Swapping Archivo for SF in the shell — the hard grotesque is the poster look.
  • Dark-by-default anything. No near-black page grounds.
  • Gradient text, glow, or bento tiles as decoration.

Node & edge graphs

flagship-project-details.css
index.css · Orchia graph

Workflow editors with editable nodes, connections, and live execution status are a résumé-backed capability, and the site renders them twice. They form a third visual subsystem with two dialects: a structural one that answers what connects to what (Artly's system architecture, drawn in content-layer tokens), and an execution one that answers what is running right now (Orchia's production graph, drawn in that product's own violet palette). Same anatomy, different questions — never mix the two palettes.

  • Edges are geometry, not decoration — cubic beziers connect aligned ports and labels stay short enough to remain horizontal in the lane gap.
  • One dialect per graph. Structure graphs use content-layer tokens and orange; execution graphs use the product palette and status colours. A graph never borrows the other's colour language.
  • Status is redundant by design — the node stroke, rail, edge, and text label all carry it. Colour alone is never the only signal.
  • Reduced motion keeps meaning: the dash flow stops and the static state diagram still reads.

Known debt

Tracked so it is not
mistaken for intent
  • Dead tokens. --cw, --color-skel, --color-orange-tint are declared and never used. --animate-enter, --animate-enter-delay, and @keyframes enter are defined but nothing references them. .site-container hardcodes the column width instead of consuming --cw.
  • Hardcoded greys in the content layer. #ececee, #e9e9ec, #eeeef0, #f3f3f5, #4c4c50 are one-off values. --story-body and --story-muted are two names for the same hex.
  • Arbitrary Tailwind values. text-[1.05rem], gap-[11px], max-w-[52ch] bypass the type and spacing scales.
  • No shared primitives. Buttons, cards, and chips are re-declared per component; there is nothing to inherit from.
  • The 8px radius is a literal, not a token, even though it is a documented step in the ladder.
  • Nothing enforces any of this. The rules live in prose — here, in DESIGN_SYSTEM.md, and in AGENTS.md. There is no lint or token check.
